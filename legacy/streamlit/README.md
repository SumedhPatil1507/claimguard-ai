# Legacy Streamlit Prototype (Archived)

> **Notice:** The primary production frontend for ClaimGuard AI has been migrated to **Next.js 14 App Router** located in `/frontend`. This folder contains the legacy Streamlit prototype preserved for historical reference and standalone demo experimentation.

### Running Legacy Streamlit

```bash
pip install -r legacy/streamlit/requirements.txt
streamlit run legacy/streamlit/app.py
```
